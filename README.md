# 📝 Just another To-Do List 

A simple to-do list web application built with **React JS** to learn the ropes of component-based development and master the ultimate developer workflow: `git push`. 🚀

## ✨ Features
* **Add Tasks:** Jot down what you need to get done.
* **Delete Tasks:** Instantly remove completed tasks.
* **Reorder:** Move items up and down the list easily.
* **Raw & Minimal:** Focused entirely on React state and logic (CSS styling coming soon!).

## 🛠️ Tech Stack
* **React JS** (Frontend framework)
* **JavaScript (ES6+)**
* **Git & GitHub** (For version control and muscle memory)

## 💡 Why This Project?
The main goal of this project was to get comfortable with React state management while practicing core Git commands:

\`\`\`bash
git init
git add .
git commit -m "feat: added basic todo functionality"
git push origin main
\`\`\`
